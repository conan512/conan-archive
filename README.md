## 🚀 راه‌اندازی رایگان روی GitHub Pages (۱۰ دقیقه، بدون هیچ هزینه‌ای)

### ۱. مخزن بساز
در [github.com/new](https://github.com/new) یک ریپازیتوری **Public** بساز، مثلاً `conan-archive`.

### ۲. فایل‌ها را آپلود کن
از این ورک‌اسپیس این‌ها را بردار و در ریپو بگذار:
```
scraper/fetch.py
generator/site.py
generator/categories.py
generator/theme.css
data/meta.json           ← اطلاعات کانال
data/posts/*.json        ← آرشیو کامل در ۸ تکهٔ ~۳.۵MB (زیر سقف ۲۵MB گیت‌هاب)
store.py                 ← لایهٔ خواندن/نوشتن تکه‌ها
.github/workflows/sync.yml
requirements.txt
```
> پوشهٔ `site/` و `media/` را آپلود نکن — هر دو خودکار ساخته می‌شوند.

### ۳. GitHub Pages را روشن کن
`Settings` → `Pages` → در بخش **Source** گزینهٔ **GitHub Actions** را انتخاب کن.

### ۴. اجازهٔ نوشتن به اکشن بده
`Settings` → `Actions` → `General` → پایین صفحه:
**Workflow permissions** → ✅ `Read and write permissions` → Save.

### ۵. اولین اجرا
تب `Actions` → ورک‌فلوی `Sync Telegram & Deploy` → دکمهٔ **Run workflow**.

بعد از ~۲ دقیقه سایتت اینجاست:
```
https://<username>.github.io/conan-archive/
```

از این به بعد **هر ۱۵ دقیقه** خودکار اجرا می‌شود: پست جدید کانال → سایت. کاری لازم نیست بکنی.

## 🌐 دامنهٔ رایگان و بهتر (اختیاری ولی توصیه می‌شود)

GitHub Pages در ایران گاهی کند است. **Cloudflare Pages** رایگان است و سریع‌تر:

1. در [dash.cloudflare.com](https://dash.cloudflare.com) → `Workers & Pages` → `Create` → `Pages` → `Connect to Git`
2. ریپوی گیت‌هابت را وصل کن
3. تنظیمات بیلد:
   - **Build command:** `pip install -r requirements.txt && python scraper/fetch.py && python generator/site.py`
   - **Build output directory:** `site`
4. Save and Deploy

آدرس رایگانت: `conan-archive.pages.dev`
می‌توانی همزمان هر دو را داشته باشی. برای دامنهٔ اختصاصی رایگان هم می‌توانی از سرویس‌هایی مثل `js.org` (برای پروژه‌های اوپن‌سورس) استفاده کنی.

## 🔧 دستورات محلی

```bash
python scraper/fetch.py              # گرفتن پست‌های جدید
python scraper/media.py              # دانلود تصاویر جدید
python generator/site.py             # ساخت سایت در پوشهٔ site/
COPY_MEDIA=1 python generator/site.py   # برای دیپلوی (کپی واقعی به‌جای symlink)
python -m http.server 8080 -d site   # پیش‌نمایش محلی
```

## 🖼 مدیا — میزبانی محلی ✅

- **۱۲٬۲۳۹ تصویر (۹۹.۷٪)** دانلود، به حداکثر ۱۲۸۰px تغییر اندازه و به **WebP** فشرده شد → ۵۳۸MB
- ۳۷ تصویر که لینکشان روی تلگرام منقضی شده بود، خودکار به CDN تلگرام fallback می‌کنند
- **ویدیوها** با تصویر بندانگشتی محلی نمایش داده می‌شوند و برای پخش به تلگرام لینک می‌خورند

```bash
python scraper/media.py                    # افزایشی؛ فقط تصاویر جدید
WORKERS=24 QUALITY=75 python scraper/media.py   # سریع‌تر / فشرده‌تر
```

اسکریپت **resumable** است: مانیفست را نگه می‌دارد و تصاویر دانلودشده یا ۴۰۴شده را رد می‌کند.

> در گیت‌هاب اکشنز تصاویر بین اجراها **کش** می‌شوند، پس فقط بار اول کند است.
