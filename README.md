# 🕵️ آرشیو کارآگاه کونان ایران

سایت استاتیک، دسته‌بندی‌شده و قابل جستجو برای کانال تلگرام [@DetectiveConanIR](https://t.me/DetectiveConanIR)
با تم معمایی تیره — که **هر ۱۵ دقیقه به‌صورت خودکار** پست‌های جدید کانال را می‌گیرد و منتشر می‌کند.

---

## ✨ چه چیزی ساخته شد

- **۹٬۸۹۷ پست** — کل آرشیو کانال از پست #۱ (نوامبر ۲۰۲۰) تا امروز
- **۹ بخش موضوعی** + **۴۲۵ صفحهٔ هشتگ** + **۷ صفحهٔ سالانه**
- جستجوی زندهٔ فارسی در متن کپشن‌ها و هشتگ‌ها (بدون سرور)
- صفحهٔ اختصاصی برای تک‌تک پست‌ها با گالری، ویدیو، فایل و لینک‌پرویو
- خروجی **RSS**، **sitemap** و صفحهٔ ۴۰۴ سفارشی
- **میزبانی محلی تصاویر** (WebP) — مستقل از فیلترینگ تلگرام
- تم معمایی: مه متحرک، نویز فیلم، درخشش قرمز خونی، فونت فارسی، کاملاً RTL و موبایل‌فرندلی
